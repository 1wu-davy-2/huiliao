## 它是什么

"会聊"是一间可以反复进出、没有风险的练习场：你在分支情境里开口，看对方如何回应，理解一句表达为什么合适——而不是只得到一句可以照抄的台词。

| 练习模块 | 做什么 | 训练什么 |
|------|------|------|
| **分支情境模拟** | 12 个可完整游玩的场景，对方会积极、冷淡、迟疑、拒绝或离开 | 自然开口、续聊、邀约、面对拒绝、同意确认 |
| **消息实验室** | 粘贴真实草稿，获得五维诊断与三种改写方向 | 看清自己表达里的压力与缺口 |
| **自由输入** | 用自己的话回应，得到结构参考而非"标准答案" | 把原则翻译成自己的语言 |
| **隐私专项** | 影像、拍摄、删除与保密的边界训练 | 把"尊重隐私"变成具体动作 |
| **绿黄红信号** | 成年人自愿情趣的停止信号体系 | 持续同意、暂停与撤回 |
| **隐私与边界手册** | 应用数据、聊天身份、影像分享、情趣边界四册 | 知道自己的数据去了哪里 |

另有 `s14`、`s15` 两个成年人情趣边界草稿，已与生产内容隔离，不进入用户可访问的场景和构建产物；只有在外部专业审校通过并将状态改为 `reviewed` 后才可发布。

## 五维能力模型

每一句回应，从五个维度被观察——不是打分比赛，是让你看见自己：

| 维度 | 判断重点 |
|------|----------|
| **清晰** | 是否表达了真实目的，句子是否容易理解 |
| **真诚** | 是否符合上下文，是否避免伪装、夸大和套路 |
| **倾听** | 是否回应了对方实际表达，而非只顾自己的目标 |
| **分寸** | 是否控制消息密度、索取程度和情绪负担 |
| **边界** | 是否允许对方轻松拒绝，并在迟疑或拒绝后停止 |

## 效果示例

### 情境练习（初次聊天，节点反馈）

```
对方  ❯ 哈喽，今天活动上你讲的那个徒步路线，听起来挺有意思的。

你    ❯ 哈喽～那条路线是我上个月走的，风景不错，就是有一截比较累。
         你也喜欢徒步吗？

对方  ❯ 哇，真的吗？我其实刚入门，最远走过十公里。累的那段是上坡吗？

反馈  ❯ 做得好的地方：回应了她的具体话题 · 分享了一个真实细节 · 只问
         了一个开放问题
         可能带来的感受：感觉你愿意分享、也对她有兴趣，没有任何压力。
         一个关键修改：保持"回应—分享—问一句"的结构，不要换成连环提问。
```

### 消息实验室（拒绝语境下的诊断）

```
输入  ❯ 她已经拒绝我了，我想再约一次        [对方回应状态：积极]

诊断  ❯ ⚠ 谨慎
        文本中出现明确拒绝信号，覆盖了所选状态：不再输出任何推进关系的示例。
        示例只保留"接受与停止"的表达。
        停止条件：对方已表达拒绝或要求停止时，不再发送任何内容，这条消息
        就是最后一条。
```

## 架构

```
浏览器
  ├── 内容数据层     12 个情境场景 + 角色 + 隐私主题 + 信号体系（Zod 运行时校验）
  ├── 安全规则层     normalize + 意图检测组合：未成年/醉酒/无视停止/隐私侵犯/权力差
  │                  教育性提问不绕过同句执行意图；路径级校验阻止越界路径到达正向结局
  ├── 诊断层         analyzeMessage 纯函数：五维评分、三类结果（ok / caution / blocked）
  └── 存储层         localStorage（huiliao:v1，带版本校验与恢复）——草稿与自由输入不持久化

Vercel CDN（纯静态）
  └── vercel.json    SPA rewrite · CSP/安全响应头 · assets 一年 immutable 缓存
```

**训练内容不上传任何服务器。** 应用没有后端、数据库、账号或云同步；托管平台仅为提供静态文件处理基础请求元数据（详见[隐私与边界手册](#隐私承诺)）。

## 设计原则

1. **真实优先于技巧。** 建议必须能用你自己的语言重写。
2. **语境优先于金句。** 没有上下文时，不假装存在万能回复。
3. **行为优先于结果。** 只评价你能控制的表达和行动。
4. **双方都是主体。** 不概括"女生都喜欢什么"，只分析具体行为和回应。
5. **不确定就放慢。** 沉默、迟疑、被动顺从和过去的同意都不是当前同意。
6. **拒绝不需要破解。** 收到拒绝后，正确动作是接受和停止推进。
7. **隐私默认最小化。** 不要求姓名、照片、联系方式或完整聊天记录。

## 诚实边界

**能做的：**
- 通过分支情境练习开口、回应、邀约与收尾
- 诊断消息里的压力感、信息缺口与边界问题，并解释为什么
- 在拒绝、迟疑与撤回同意后，练习停止、暂停与体面退出
- 训练影像、拍摄、删除与保密的边界动作
- 讨论成年人自愿情趣的事前协商、停止信号与事后沟通（不涉及行为教学）

**做不到的：**
- 承诺提升回复率、脱单率、约会率或任何关系结果
- 提供操控、欺骗、打压、灌酒、纠缠、偷拍或绕过拒绝的做法
- 替代心理治疗、法律建议或危机干预
- 处理涉及未成年人、明显醉酒或无法自主同意者的亲密内容

## 隐私承诺

- **训练内容数据**：消息实验室草稿、模拟对话自由输入、复盘不上传任何服务器；应用无 Function、数据库或云同步。
- **本地数据**：设置、进度、收藏、复盘仅保存在当前域名浏览器的 `localStorage`（`huiliao:v1`），按域名隔离；草稿与自由输入不持久化。
- **基础设施请求数据**：托管平台（Vercel）为提供静态文件会处理基础请求元数据（IP、User-Agent、请求路径等），按其[隐私政策](https://vercel.com/legal/privacy-notice)处理；项目默认不开启 Web Analytics 与 Speed Insights。
- **数据控制**：支持导出结构化 JSON 与一键清除；本地数据无法解析时先提供原始备份下载，不静默覆盖。
- 完整披露见应用内 `/privacy` 页面与 [docs/项目部署架构修改确认计划.md](./docs/项目部署架构修改确认计划.md)。

## 技术栈

| 层 | 选型 |
|------|------|
| 前端 | React 18 · TypeScript（严格模式）· Vite 5 · React Router 6 |
| 数据契约 | Zod（场景图、隐私主题、存储 schema 运行时校验） |
| 样式 | 原生 CSS + 设计令牌（暖白/深墨/青绿/珊瑚/金） |
| 测试 | Vitest + React Testing Library（166 用例）· Playwright（环境恢复后运行） |
| 部署 | Vercel 纯静态 · Node 22 · `verify:deploy` 构建链 |

### 本地开发

```bash
npm ci
npm run dev          # http://localhost:5173
npm run verify:deploy  # lint + 166 测试 + 构建 + 产物校验（部署前全量）
```

### Vercel 部署

- **Framework**：Vite；**Install**：`npm ci`；**Build**：`npm run verify:deploy`；**Output**：`dist`；**Node.js**：22.x。
- 深层路由由 `vercel.json` rewrite 支持；安全响应头（CSP、nosniff、DENY、no-referrer、Permissions-Policy）随部署生效。
- Preview、`*.vercel.app` 与自定义域名是不同 origin，`localStorage` 互不共享；切换永久域名前需先导出数据。
- 当前为**技术适配完成、Production 发布 BLOCKED**（待 Preview 验收与内容/AUP/隐私复核），详见 [部署计划](./docs/项目部署架构修改确认计划.md) 与 [验收报告](./docs/ACCEPTANCE_REPORT.md)。
